Privacy Policy

This application is a personal tool operated by the owner of the TikTok account @thecuriola. It is not distributed to third parties, has no other users, and is not offered as a service.

Data it accesses

  • Basic profile information of the authorizing account (open_id, display name), used only to confirm which account is being posted to.
  • Video files created by the operator on the operator's own computer.

Data it stores

  • An OAuth refresh token, stored locally on the operator's computer in a private file excluded from version control.
  • No data is transmitted to any server other than TikTok's official API endpoints.

What it does not do

  • It does not collect data from other users.
  • It does not share, sell, rent, or transfer any data to third parties.
  • It does not use analytics, advertising, or tracking SDKs.

Retention and revocation

Access can be revoked at any time in TikTok: Settings → Security & Permissions → Manage app permissions. Deleting the local credential file removes the stored token from the operator's computer.
